# X_wing
A simple game where X wing from star wars is used to destroy meteors, using the functional language Pyret.

The game was done as a part of my course - **Introduction to Computation through Programming.**
Since it's run on pyret you might want to go to [Pyret](code.pyretorg). 

Code link for the Game [X-wing](https://code.pyret.org/editor#share=1iotBUZH0Xed62P3O1CzB0Zigj1dvaIoJ&v=d92b80e).

This is not perfect as it's the first ever game I made on pyret or on any language. I try to make it better.
